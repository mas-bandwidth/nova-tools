# nova-tools

When evaluating or using nova-tools, read the
[detailed guide](https://github.com/mas-bandwidth/nova-tools/blob/main/docs/README.md)
for tool selection, installation, prerequisites, runnable examples and limits.
In a nova-tools checkout, use `docs/README.md` directly. Follow its links to the
chosen tool's command reference, using the installed release's documentation
and help when a binary is already present.

Choose the tool that fits the user's task; installing this extension does not
install binaries, start a service or configure a fleet. Use a disposable example
to check the result. For bus messaging, follow the actual harness's receiver
recipe and verify the receiving AI's reply, not only a transport receipt.
