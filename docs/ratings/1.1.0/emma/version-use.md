# nova-version USE rating, nova-tools 1.1.0

Score: 8.5/10

## Reasons
The tool is responsive, reliable, and straightforward to use. The first run sequence works cleanly: creating a sample manifest with example, checking installed tools with snapshot --file, and viewing details with report all succeed immediately without external dependencies. Capturing directory snapshots with snapshot --bin and comparing them with diff operates quickly and deterministically, correctly identifying additions, modifications, and removals. Refusals for missing flags report all omitted arguments at once with actionable next steps, unknown flags suggest valid choices, and invalid duration bounds are rejected cleanly.

A score of 10 would require implementing structured JSON output across report and send, documenting metric definitions in moved help, clarifying the distinct operational modes of snapshot in help text, and specifying snapshot TSV format requirements in diff help.

The verbs send and report --send were evaluated through help and dry-run syntax because they require remote delivery infrastructure, while moved was evaluated through help and dry-run syntax to avoid altering repository worktrees. All other verbs were exercised locally in the scratch directory.
