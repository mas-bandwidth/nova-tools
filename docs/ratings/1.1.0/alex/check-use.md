## Reasons

Used cold from the help, everything run in a scratch directory: a records tree and a git repository of my own, no store, no remote, no forge, no key. The first run works from the binary alone: the banner's two setup lines and its example block ran as printed, exit 0, and the closing line named the next four verbs and what each one wants. Two real jobs ran end to end. The records job: quickstart found a broken link and a code file in one run and printed both checks' verdicts with a FAIL closing line naming both; attest hashed a manifest; corpus checked a ledger — and when spelling --write fixed one word inside a protected fragment, corpus named the row, the ledger line and the repair, then went green once the row moved in the same commit, which is the whole contract taught in one sitting. The branch job: hygiene over a git repository I made printed identity, out-of-path and stray-file findings in one run, and its capped MORE line carried a command that ran as pasted; nocode --staged caught a staged shebang script and went clean when it was unstaged. A third loop closed: dogfood record, ledger, gate naming an open edge with its id and both ways to close it, then green after a --closes receipt.

The refusals are the strongest part. A missing flag names the flag, a hint saying what it wants, and the door; attest with nothing named both flags at once; the unknown verb lists every verb; a bad value names the value; dogfood record suggests the nearest verb by spelling. --json on links, attest and hygiene printed the same reading as one object with the shown and total. --dry-run is offered by no verb: spelling's check mode is the preview of --write and the help says so, but record writes with no preview. Where I had to guess: the hygiene finding says commits are "not the pool's identity", and the pool is private vocabulary for the identity set I named; and the ledger's four-column shape lives in the banner's trailing notes rather than the example block. Verbs not tried: convergence, which reads the forge through gh — judged from help, and its empty run names all five flags with hints; floors, whose cold run can only fail because no source pair ships; and nocode's --deny-ext and --allow tuning, judged from --print-deny-list. A 10 would need the zero-file greens closed, the floors pair shipped, the unknown-flag door narrowed to the verb, and plain nouns in the output lines.
