This rates nova-self-talk as it stands at the tip of sprint/mechanical-2026-10-02, the release candidate for v1.2.0 (no v1.2.0 tag exists on the forge yet). `nova-self-talk version` prints `nova-self-talk v1.0.1-0.20261007220135-81b318639963 linux/amd64 go1.26.6`. Built and run on a Linux bench machine, in a scratch directory made for the trial; no live store, no server, no network. This file carries attempt 2's rating (head 46841bba7968bf622553f5855d266678d99d40b3) onto this build and re-ran the trial there; the reader's fix stands, and every Findings row names one place or one command. Every verb was run cold: help (bare, per verb, and with an unknown name), scan (a page of my own carrying every shape, the example pages, a clean page, an empty page, standard input, a directory, a bare word, a missing path, a byte page of random data, and a text page holding a NUL byte), shapes (lines and `--json`), example (`--dry-run`, the first write, the second run, a changed page, an unwritable path), and the refusals (unknown flag, missing value, `--max abc`, `--max -1`, a skip by path, an empty skip, flags before, between and after the files, and `--`).

## Reasons

READ. The banner answers the three questions in its first nine lines: what it flags (a standing self-verdict, in two disjoint classes), how it reads (each named file sentence by sentence against one table of shapes, a dated claim never flagged), and the first run (`nova-self-talk example ./pages`, then three lines each said in advance to exit 1). Both classes are glossed where they are named, with a shape and an example each, and the licences are listed in the same paragraph. `shapes` prints the live detector table the scan walks, one row per rule with a sentence it finds (`finds=`) and a near miss it passes (`passes=`), and the NOTE says how to read a licensed row. The output grammar is stated line by line with its stream, the exit table is stated once and covers the all-skipped case, and the flags say their defaults. `docs/CLI.md` opens with a `### First run` whose transcript is the shape the binary actually prints for the example pages, line for line.

What keeps READ at 8. The banner is 94 lines (cmd/nova-self-talk/main.go:28-121), with the print-line inventory and a flags essay between the usage block and the examples. The per-verb help is thinner than the banner and in places wrong for the verb: `scan -h` prints `usage: nova-self-talk scan [flags]`, dropping the required `<file>...`, `example -h` drops `<dir>`, and `version -h` claims `[flags]` the verb does not take; every verb's `-h` ends with the scan's exit table including the all-skipped clause, `version -h` and `shapes -h` too; `--skip` and `--rule-doc` print `<value>` where the banner says `<basename>`. The spec has drifted from the binary in one load-bearing place: the banner and the code take flags before, between or after the files, while the normative docs/SPEC.md:1888 still says "Flags must precede filenames" and "A late flag refuses before any file is read", and docs/CLI-STYLE.md:7 says a late flag is refused; an AI that trusts the spec writes a wrong test. The "Says NO" grammar at docs/SPEC.md:1870 is `STANDING: <claim>` where the binary prints `STANDING match="<words>": <sentence>`; docs/SPEC.md:1752 opens a paragraph with "The checks above are walls" when no check stands above it in the section; docs/SPEC.md:1810 cites "Specimen 8" without saying what it is. The internal map row still calls the package an "agent self-talk journal stream" (internal/docs/catalog.go:111), and the README row's first command scans a path only a repo checkout has (README.md:40).

USE. The first run is as clean as any tool in the set. `example --dry-run ./pages` says what it would write and the next command; the real write lays down two pages; a second run writes nothing and reports `kept=`; a changed page is refused, never replaced. The pasted example lines exit 1 with findings on stderr in line order, the DATED count and the count line on stdout. The tool refuses to guess: no default file set, no directory walk; a missing path and a bare word are named, and every unreadable file is reported before anything is scanned, with "NOTHING was scanned, which is not a green". A byte page of random data is now refused as not valid UTF-8, which closes the 1.1.0 green-over-a-binary defect. Flags stand before, between or after the files, `--` ends them, `-` is standard input, and an unknown flag is rewritten to `unknown flag -bogus; the flags are ...`. `--max` caps each class separately with a `MORE` line naming its remedy, in lines and in `--json` (`more` carries kind, shown, total and remedy); `--json` is the same value as the lines. `--skip` and `--rule-doc` are reported on their own lines, a name that matches nothing gets a NOTE, and an all-skipped run is `SELFTALK SKIP files=0`, never OK.

What keeps USE at 8.5. The flag parse stops at the first error: `--bogus --max abc mine.md` names only the unknown flag, though the code's own comment says every problem is named in one go. `--max abc` refuses in the flag library's voice while `--max -1` gets the tool's own sentence. `help frobnicate` prints the whole banner at exit 0. `example --bogus` says `flag provided but not defined`, the library's words scan rewrites. `version extra` says "got 1" instead of the word and points at `version -h` where every other verb points at `help <verb>`. The finding kinds' MORE lines print on stderr, contradicting pkg/tool/out.go:135 and docs/SPEC.md:298, which place a tool's informational tokens on stdout; under the banner's own `2>/dev/null` recipe the line that says findings were cut disappears. `example --dry-run /proc/nope` promises `would-write=RULES.md,journal.md` at exit 0 where the real run refuses; with the pages already in place it prints `would-write=-` and still offers `run: nova-self-talk example ./pages`, a command that would do nothing. A file holding a NUL byte is valid UTF-8, so it is scanned as prose and can print a green.

A 10 would place MORE with the family on stdout, name every flag problem in one refusal in the tool's own voice, make `help <unknown>` say so at exit 2, give each verb's `-h` its real usage line and its own exit table, make the dry run check what the real run needs, refuse a page that is not text, and bring the spec's flag rule, grammar and line references into line with the binary.

## Good, keep

- `shapes`: the live detector table, each row with a sentence it finds and a near miss it passes, run through the scan by the tests, plus a NOTE on how to read a licensed row. A pattern tool that shows its patterns and proves them is the right answer to "what will this flag".
- All-or-nothing reads: every unreadable page is named before anything is scanned, the run says "NOTHING was scanned, which is not a green", invalid UTF-8 is refused by name, and an all-skipped run is `SKIP files=0`, never OK.
- The every-run NOTE saying a green clears the known shapes, never the file, and the DATED count on one line: the tool says what it cannot see and does not spend the reader's context on the good news.
- `example` never replaces a page: a changed page is refused before anything is written, an identical one is kept and reported as `kept=`, and the dry run names the next command.
- The two classes with their seam at `I cannot`, the licences (instrument, aspiration, imperative, quotation) named where they are defined, and `--json` rendering the same value as the lines.
