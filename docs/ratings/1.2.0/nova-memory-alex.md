# nova-memory READ and USE rating, nova-tools 1.2.0

Rater: Claude Opus 5.5 in Claude Code, a sprint worker on a friend's re-rate card
Build: 43b487125e85
READ: 7/10
USE: 7/10

No v1.2.0 tag exists on the forge yet, so this rates the release candidate at the head of sprint/mechanical-2026-10-02. `nova-memory version` prints `nova-memory v1.0.1-0.20261006145252-43b487125e85 linux/amd64 go1.26.6`. Built and run on a Linux bench machine, in scratch directories made for the trial: the banner's two-file corpus, then a second corpus with frontmatter notes, wikilinks (plain, aliased and dangling), a CRLF file, an index with a dead anchored link, a dated log with a blockquote, a second root, a pin file and a gold.tsv. All eight verbs were run, each refusal path the help names was tried, and `--json` was tried on every verb. No live store, no server.

## Reasons

READ. The banner is one of the best in the set: one line on what the tool is, one paragraph on how it works, a typed sample of every line it prints, the full usage block, a flag list where every required flag says why it is required, the exit codes by verb, a four-line `setup:` and an `example:` that run as printed. The spec section (docs/SPEC.md:2335) says which two verbs are checks and which five only report, and why `check` must never be gated on. An AI can start from the help alone.

What keeps READ at 7. The help's own interpretation rule for the CAL line is contradicted by its own example: the banner says a hit at or below the CAL score is "no better than noise", then prints the correct rank-1 hit at `score=0.99` under `CAL score=1.46` (cmd/nova-memory/main.go:46-52). The gold.tsv format for `eval` is not in the help; only the spec (docs/SPEC.md:2732) and one refusal say it. `boot` has no example, its output is never described in the help, and the spec says in one place what boot does and in another that the tool is "Not the boot" (docs/SPEC.md:2807, cmd/nova-memory/main.go:12). Every verb's `-h` repeats the whole tool's exit-code paragraph, starting with the garbled "by verb (each ran here), search, stats, boot: 0 ran" (cmd/nova-memory/main.go:143), instead of that verb's exit codes; `version -h` and `boot -h` say "the index lives in memory for the run" though neither builds an index (cmd/nova-memory/main.go:252). `verify -h` says `--root` is repeatable (cmd/nova-memory/main.go:376) and verify refuses two roots. The `-h` flag lists print `<value>`, `<string>` and `<int>` where the banner says `<dir>`, `<glob>` and `<n>`, and verify's and eval's wrapped usage lines lose their indentation. The spec's search section still describes the 1.0 output (`top k files ... file:para address ... normalized snippet`, and `SEARCH OK query=<q> hits=...`, docs/SPEC.md:2571-2576) where the binary prints `file:line`, the original snippet, and the query last after `: `.

USE. Everything the banner says runs, runs. quickstart prints each command line above its output, and the lines it prints run by hand. search and check are fast and deterministic, line numbers are right after frontmatter and in a CRLF file, emphasis and blockquote markers do not hide a phrase, a frontmatter `name: x lockdown=clear` is escaped to one token, and a second root is named on every receipt. Refusals are good: missing flags come all at once with a hint each, `--k 0`, `--channels bm25,`, `--channels ./corpus`, `--floor 0`, `--coverage` without `:`, an empty coverage side, `--exempt` without `--frontmatter`, and a verify that cannot fail are all refused with the reason; boot refuses a duplicate, absolute, non-canonical, escaping, missing or non-regular pin entry. verify found the dangling wikilink (gating or not, as asked), the unindexed note, the dead `gone.md#top` link and the missing `name:`, and resolved the aliased `[[bench-only|...]]`. eval failed under its floor with exit 1 and passed at it.

What keeps USE at 7. The CAL band, the one number the tool gives for "is this hit real", misleads in both directions. It is the score of a 16-word probe sentence that shares function words with any English corpus (cmd/nova-memory/main.go:206), compared against queries of one to five words: an exact single-word hit (`workstation`, 1.58) sits under the band (1.97), while a draft paragraph about quokkas on Rottnest, which nothing in the corpus mentions, gets a rank-1 hit at 2.15 above it. With two channels the CAL line reports the bm25 score of the probe's fused top hit (0.69) rather than the bm25 band (1.97 on the same corpus), so the band for a channel moves with the channel set. Overlapping roots are indexed twice: `--root . --root .` reports `files=10` for five files, and `--root memory --root .` spends two of k receipts on the same paragraph. `--exclude logs/` and `--exclude nomatch` exclude nothing without a word. check drops a candidate paragraph under three terms without saying so (`candidates=2` for a three-paragraph draft). eval and boot report only the first bad input per run, against the help's "every flag it can see at once": `--floor 1.5 missing.tsv` names only the floor, a gold file with three bad rows names only row 1, a pin with four bad entries names only the first. A gold file's header row is scored as a query. `boot` prints `BOOT OK files=3 bytes=684` and loads nothing for the session and names no path, so its use to an AI is a byte count. Snippets are cut at 120 bytes mid-word in text and in `--json` (internal/memindex/memindex.go:268), with no way to see the rest but opening the file.

A 10 would make the CAL band a per-hit verdict a reader can trust (probe the same length as the query, or score the probe per query, and print the band per channel), put the gold.tsv columns and boot's output and purpose in the help, give each verb's `-h` its own exit codes, dedupe overlapping roots, report an exclusion or dropped paragraph that changed nothing or something silently, report every bad gold row and pin entry in one run, and let `--json` carry the whole paragraph.

## Good, keep

No defaults, and every required flag says why it is required; the refusal for a bare `search lantern` names all three missing flags with a hint each. quickstart, which prints each step's real command line above its output and closes by saying its choices were choices. The `setup:` and `example:` block, which runs as printed. Determinism and the one-line guarantee: frontmatter text cannot forge a field. verify's refusals of a check that cannot fail, an empty glob side, and `--exempt` alone. eval's refusal of a zero floor. The `SEARCH NOTE lexical only` and `MEMORY NOTE ... verdict stays yours` lines on every run. The spec's STATUS section, which says the value is unproven and ships eval so the reader can measure it.
