# nova-memory READ and USE rating, nova-tools 1.2.0

Rater: deepseek/deepseek-v4.1-flash in the opencode harness, a friend on a re-rate card
Build: c76fcb249cc1
READ: 7/10
USE: 7/10

No v1.2.0 tag exists on the forge yet, so this rates the release candidate at the head of sprint/mechanical-2026-10-02 as staged for this card. `nova-memory version` prints `nova-memory v1.0.1-0.20261007015429-c76fcb249cc1 linux/amd64 go1.26.6`. Built and run on a Linux bench machine, in a scratch directory made for the trial: the banner's two-file corpus built from its own `setup:` lines, then a long note whose answer a 120-byte snippet cuts, a note with a three-blank-line gap, a corpus with a `***` name block and a real frontmatter note, two-root and `--exclude` runs, a gold file, and a pin file with two bad entries. No live store, no server.

## Reasons

READ. The banner is a good door. Line 1 says what the tool is for, `how it works:` says the index is built in memory per run and nothing is written, the `setup:` block makes a corpus in four lines, and every line under `example:` runs from that corpus unchanged. Every required flag says why it is required, every verb's `-h` carries its synopsis, a worked example, an `effect:` line and its flags, and the tool's section in docs/CLI.md:339-426 is the best first-run writing in the set: a real transcript, what flags want, what the output means, the read caps, and the reason the tool exists. docs/CLI.md:426 points at `cmd/nova-memory/testdata/example-gold.tsv`, whose header spells the gold format — `query<TAB>expected-path-substring[,substring...]`.

What keeps READ at 7. The first thing the banner teaches is the CAL rule: a hit at or below the CAL score "is no better than noise" (cmd/nova-memory/main.go:54). The banner's own example then shows its rank-1 hit at score=0.99 under CAL 1.46 (cmd/nova-memory/main.go:57), and docs/CLI.md:416 repeats the rule over the fixture quickstart whose three right answers (3.48, 3.12, 2.97) are all under CAL 4.05. A reader who follows the rule throws away the right answer; a reader who notices the contradiction stops trusting the line. The gold format is in the spec but not in `eval -h`, and a header-looking first line is scored as a query rather than skipped: `query<TAB>expected_file` prints `EVAL MISS query=query expected=expected_file`. check's lines lead with `MEMORY` where every other verb leads with its own name; docs/SPEC.md:293 states the exemption but the first-run transcript (docs/CLI.md:379) and its Reading-it paragraph (docs/CLI.md:416) never do. Every `-h` repeats the whole exit-code paragraph, whose first sentence "by verb (each ran here), search, stats, boot: 0 ran" does not parse cold (cmd/nova-memory/main.go:143). `version -h` and `boot -h` both say "(the index lives in memory for the run)" though version builds none (cmd/nova-memory/main.go:252). `verify`'s usage marks `--coverage` and `--frontmatter` optional while a run with neither and `--links info` is refused (cmd/nova-memory/verify.go:65), so the minimal usage line in the banner does not run as printed.

USE. The first run is the banner's: `quickstart --root ./corpus` runs stats, one search and one check, printing each command line above its output, and ends saying bm25 and k=3/2 were choices, not defaults. search, check (file and stdin), stats, verify (gate, info, coverage, frontmatter), eval (pass and fail), boot, two roots, `--exclude`, `--` before a dash word and `--json` on every verb but version all did what the help says. Missing required flags, an unknown flag, an unknown channel, `--k 0`, `--floor 0`, `--floor 1.1`, an empty draft and an empty corpus each refuse once with a reason and a `run:` line; a miss is exit 0 with a MISS line; an unknown flag names every flag the verb takes.

What keeps USE at 7. The CAL line called every right hit noise in every multiple-term run I made: 0.99 under 1.46 on the banner's corpus, and on the fixture quickstart 3.48, 3.12 and 2.97 under 4.05; the verdict a reader needs is absent from the HIT line. Snippets stop at 120 bytes (internal/memindex/channels.go:321), in the JSON too, so the long note was cut mid-sentence before the words I searched for, and no flag widens it. `--exclude logs/` silently excludes nothing (files=2, the log's class still printed) while `logs` and `logs/*` both work (cmd/nova-memory/main.go:381-392); no NOTE says an exclusion matched zero files. `boot --json` reports `files` and `bytes` and no path, so the loaded memories are hidden unless the pin file is reread (cmd/nova-memory/boot.go:50). search's `--json` hit carries `"candidate": 1`, a field of check's paragraphs that is meaningless in search (cmd/nova-memory/retrieval.go:63). `verify --root x --links info` (the minimal banner usage) is REFUSED, and missing-flag refusals end `run: nova-memory help`, the whole banner, while the unknown-flag refusal on the same verb ends `run: nova-memory search -h` (cmd/nova-memory/main.go:360, main.go:345). boot reports the first bad pin entry and stops, so a two-entry mistake took two runs (cmd/nova-memory/boot.go:114-126).

A 10 would make the CAL rule match what the tool's own examples show, quote the gold format in `eval -h` and skip a header line, say boot validates and prints no content, let a caller see a whole passage, make `--exclude` accept a bare directory and say when it matches nothing, print the loaded paths, drop `candidate` from search, state that verify needs at least one gating check, and send every refusal after a verb to that verb's `-h`.

## Good, keep

The index is built in memory each run and nothing is written; every verb's `-h` says so on its `effect:` line. Every required flag is required for a stated reason, and a refusal names all the missing ones at once with a hint each. An unknown flag lists every flag the verb takes and points at `search -h`. quickstart prints each command above its output and says at the end which choices it made for you. Every receipt carries class, root and `file:line`, and the log-class NOTE is a good guard against mistaking a record for a lesson. `--json` is one result value on every verb but version, a refusal included, and the inspection and verification verbs all gained it. verify bounds findings per kind with the totals always printed, verify caps each kind separately so wikilinks cannot bury a frontmatter finding, and eval refuses a floor that cannot fail.
