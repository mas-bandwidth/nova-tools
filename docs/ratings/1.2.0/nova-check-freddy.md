# nova-check READ and USE rating, nova-tools 1.2.0

Rater: Claude Opus 5.5 in Claude Code, a sprint worker on a friend's re-rate card
Build: 43b487125e85
READ: 7/10
USE: 8/10

No v1.2.0 tag exists on the forge yet, so this rates the release candidate at the head of sprint/mechanical-2026-10-02. `nova-check version` prints `nova-check v1.0.1-0.20261006145252-43b487125e85 linux/amd64 go1.26.6`. Built and run on a Linux bench machine, in a scratch directory made for the trial; no live store, no server. Read cold: `nova-check help`, every verb's `-h` (dogfood and its three sub-verbs included), docs/SPEC-CHECK.md and the nova-check sections of docs/CLI.md and docs/SPEC.md. Every verb ran: the banner's setup and three example lines; quickstart, links, kernel (bytes and tokens), nocode (tree, `--allow`, `--deny-ext-add`, `--print-deny-list`, `--staged` in a throwaway git repo), attest, corpus, floors, spelling (`--dir`, `--file`, `--path`, `--ignore`, `--write --dry-run`, `--write`), hygiene on a two-commit throwaway repo with a foreign author, a fake key, a stray file and an out-of-path file, dogfood ledger, record and gate (with `--cli` and with `--tools`), and convergence with a fake `gh` that prints `[]` and a `--state` file. The forge was never read.

## Reasons

READ. The banner opens with what the tool is and what it writes, then one usage block for every verb, the `--json` and `--max` rules, the exit table, a two-line setup and three example lines. Every verb answers `-h` with its usage excerpt, an `effect:` line that says what it reads and writes, its flags and the exit codes, and the effect lines are honest: convergence says it reads the forge over the network, spelling says `--write` edits in place. The 1.1.0 cap-flag split is gone: every listing takes `--max`, and `--fail-max` is accepted with a NOTE. The banner now says outright that quickstart and dogfood print typed lines and no `--json`.

What keeps READ at 7. The banner is 134 lines (cmd/nova-check/main.go:32 to main.go:165) and its line 39 says "first run: create the small markdown tree below", which sits 110 lines further down at main.go:150. The verb excerpts in `-h` lose the banner's columns, so the description of quickstart, links, hygiene and convergence prints as loose fragments ("then nocode. Both run even if the", "first says NO."). `dogfood -h` and `dogfood record -h` both carry a stray line, `nova-check dogfood record the finding`, which is the tail of convergence's description (main.go:126) picked up as a dogfood usage line. Several `-h` pages disagree with the banner: `quickstart -h` lists `--exclude`, which the banner usage does not; `convergence -h` lists `--gh`, `--git`, `--now` and `--timeout`, none in the banner; `hygiene -h` does not mark `--identity` required though the verb refuses without it; `dogfood ledger -h` and `gate -h` mark neither `--cli` nor `--tools` as one-of-required; `--max` never shows its default of 20 in any `-h`; `--authors` prints its placeholder as `<<tool> <verb> = <who wrote it>>`. The vocabulary is still private: self repo, door, seed, floors, corpus, the pool's identity, pit-stop ledger and edge reach the reader with no definition on the first-run path. The docs drift from the binary: docs/SPEC-CHECK.md:1 is titled "nova-dev convergence" and says at docs/SPEC-CHECK.md:10 that help prints `nova-dev convergence ...` byte for byte, which it does not; docs/SPEC.md:353 still says every listing takes `--fail-max`; README.md:54 still calls the commands 1.0.0 and installs `@v1.0.0`. One binary still carries eleven verbs whose only common thread is the word check.

USE. The setup and all three example lines ran as printed and exited 0. Refusals are a strength: missing flags are all named at once with a one-line reason each (corpus and convergence name three and five), a zero or negative value is refused with why, `kernel` refuses a token budget without a measured divisor, `--kind bogus` lists the kinds, and `dogfood record --verb nosuch` offers `did you mean: nova-check links`. attest refuses an empty manifest and an empty file, corpus catches both a lost fragment and a shrunk ledger, nocode's `--staged` caught a staged `.go` file, hygiene found all four planted problems without printing the key, and its MORE line is a pasteable command. `--json` on links, kernel, nocode, attest and hygiene is one object with a `more` marker; `spelling --write --dry-run` printed the fixes and wrote nothing (the `--write` run after it still found and fixed both words).

What keeps USE at 8. The 1.1.0 traps are mostly still there. links and spelling over an empty directory are OK exit 0, and quickstart over the same directory is `QUICKSTART OK` even after nocode's own NOTE that it classified nothing. `--exclude ./self/sub` (the path as the user sees it) excludes nothing and says `excluded=0`; only `--exclude sub` works, and `--file self/a.md` is likewise read relative to `--dir`, reported as a broken link with `links=0 broken=1`. A failing links or attest run prints nothing on stdout; hygiene is the reverse, findings on stdout and the FAILED summary on stderr. Refusals still point at the whole help, and an unknown flag hides the rest (`links --bogus --alsobad` names one, and not the missing `--dir`). spelling did not flag `sentance` in a sentence where it flagged `teh` and `recieve`. `convergence --dry-run` still runs `gh pr list` first, so it cannot run offline, and the failure line ends `no such file or directory: ;`. A second convergence tick a second after the first exited 1 as two consecutive widening ticks, while its JSON verdict said `WARN`. `dogfood gate --require-all` told a non-author who filed a `--not-ok` receipt "only the author has run it". New edges: dogfood prints `FAIL` where every other verb prints `FAILED`; convergence's text line prints `source=--repo\x20(no\x20integration...)`; spelling's `--json` still turns `--dir` into an absolute path, home directory included.

A ten needs: a warning and a non-zero exit (or a NOTE in every verb) for a check over nothing; one path base for `--exclude` and `--file`, said in `-h`; one stream rule for findings and summaries; every refusal pointing at the verb's `-h` and naming every problem; `-h` pages that match the banner and keep its columns; a banner whose first run comes first; and docs that say what the binary does.

## Good, keep

Every refusal for missing flags names all of them at once, each with a reason line that says what the flag wants and why it is never guessed. The `effect:` line on every verb says exactly what it reads and writes, network included. attest refuses an empty manifest and a zero-byte file; corpus treats a shrunk ledger as a finding the rows themselves cannot report; kernel refuses a token budget without a measured divisor. hygiene finds identity, out-of-path, stray-file and secret findings in one run, never prints the secret, and its MORE line is a command a caller can paste. `spelling --write --dry-run` shows every fix and writes nothing, and fenced and inline code are left alone. `dogfood record --verb nosuch` suggests the nearest declared verb, and `dogfood gate` names the receipt id and the exact `--closes` that clears an edge. The cap flag is one name now.
