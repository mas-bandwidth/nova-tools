# nova-self-talk READ and USE rating, nova-tools 1.2.0

Rater: Claude Opus 5.5 in Claude Code, a sprint worker on a friend's re-rate card
Build: e26adab23ab1
READ: 8/10
USE: 7.5/10

No v1.2.0 tag exists on the forge yet, so this rates the release candidate at the head of sprint/mechanical-2026-10-02. `nova-self-talk version` prints `nova-self-talk v1.0.1-0.20261006143828-e26adab23ab1 linux/amd64 go1.26.6`. Built and run on a Linux bench machine, in a scratch directory made for the trial: the example pages, hand-written pages of probe sentences, generated pages up to 10.8 MB, standard input, and the repository's own `docs/*.md` (61 files, 2.7 MB) as the real corpus. No live store, no server.

## Reasons

READ. The banner answers the three questions an AI asks first: what it is (one line), how it works (one paragraph) and the first run (`example ./pages`, then three lines to paste, each said in advance to exit 1). The two classes are glossed with an example of each shape, the output grammar is listed line by line with which stream it goes to, the flags say their defaults, and the exit table covers the all-skipped case. `shapes` turns the detector into a readable table, each row with a sentence it finds and a near miss it passes. That is what an AI needs to trust and predict a classifier.

What keeps READ at 8. The banner is still 94 lines (cmd/nova-self-talk/main.go:28-121) and says the output contract a second time in docs/CLI.md and a third in the spec. The per-verb help is thinner than the banner: `scan -h` and `example -h` print `usage: nova-self-talk scan [flags]` and `example [flags]` with no `<file>...` or `<dir>`; `--skip` and `--rule-doc` print `<value>` and `--max` `<int>` where the banner says `<basename>` and `<n>`; `shapes -h` breaks its quoted line so the continuation reads as a second command; `example -h` picks up the setup line `nova-self-talk example ./pages` as if it were usage; `version -h` and `shapes -h` end in the scan's exit table, findings and all-skipped included. The spec's output grammar (docs/SPEC.md:114-115 and docs/SPEC.md:1870) still says `SELFTALK FAIL <file>:<line>: STANDING: <claim>` with no `match=`, which the binary always prints. The internal map still calls the package "agent self-talk journal stream" (internal/docs/catalog.go:111). The README row still says "Reads the example without editing it" (README.md:40), which names no example.

USE. The interface is close to 10. `example --dry-run`, the write, and the re-run that keeps the pages (`wrote=- kept=RULES.md,journal.md`) make the first step safe; the three banner lines run as printed and exit 1 as promised; the README command runs. Findings go to stderr in line order and counts to stdout; with `2>&1` in one process the stream reads in order, the `RULEDOC` banner above its findings. `--max` caps each class separately with a `MORE` line naming its remedy, in lines and in `--json` (`more` carries kind, shown, total, remedy). Every refusal I provoked ends in a runnable command: no files, a directory, a bare word that is no file (told the verbs and `./frobnicate`), two unreadable paths (both named, then "NOTHING was scanned, which is not a green"), a path given to `--skip`, an empty `--skip`, a late flag, `--max -1`. A refusal after `--json` answers as JSON. A `--skip` or `--rule-doc` name that matches nothing gets its own NOTE. CRLF files, a file name holding a newline (escaped `a\x0ab.md`) and `-` for stdin all work.

What keeps USE at 7.5 is the classifier on real prose. Over the repository's own docs every one of the 8 STANDING findings is a false positive, and the finding text is not a sentence: the first class's claim pattern takes up to 120 bytes before the marker (internal/selftalk/selftalk.go:56), so text opens mid-word (`md:4: STANDING ...`, `erbs are out of the habituality markers ...`, `day five cards held ...`) and an AI cannot see the claim it is told to date, cut or relocate. Fenced code blocks are scanned as prose, so every transcript of the tool in docs/CLI.md and docs/TESTS.md is a finding, and a table row and the code block after it merge into one claim (`col I am bad at tables I am terrible at code blocks.`). Negation is flagged: `I am not bad at this anymore.` and `I am no longer the worst at reviewing.` are STANDING. A third-person sentence with `every time` and `failed` is STANDING (the marker list includes `every time`, `reliably` and `in one direction`, which carry no first person). The FORECLOSURE `there is no` rule matches the letter i: `There is no -i: a key named on argv is a key in every ps.` (docs/SPEC-UPDATE.md:602) and `There is no quickstart: nothing here has a default to guess.` (docs/USAGE.md:189) are findings. A sentence ending `."` does not end, so `She said: "I am the worst at this."` and the next line's `I will never be a good planner.` print as one FORECLOSURE at the first line. Throughput is about 6 s per MB (2.7 MB of docs in 18.5 s, 10.8 MB in 65 s, linear), slow enough that a memory directory scan is felt. The three interface carry-overs from 1.1.0 remain: the first refusal hides the second, `help frobnicate` is the banner with exit 0, and `--max abc` refuses in the flag library's voice.

A 10 would make each finding's text the sentence that holds the claim, skip fenced code, let negation (`not`, `no longer`) and third-person sentences pass, tie the `there is no` rule to a word and not a letter, end a sentence at `."`, name every invocation problem in one refusal, refuse `help <unknown>`, and give the per-verb help the banner's placeholders.

## Good, keep

- The first run: `example --dry-run`, a write that keeps identical pages and refuses different ones, and three pasteable lines each announced to exit 1. Nothing about the first five minutes needs guessing.
- Refusals that end in a runnable command and never pass for a green: an unreadable path says NOTHING was scanned, a bare word is told the verbs, a path given to `--skip` is told it takes a basename, and `--json` refusals are JSON.
- `shapes`: the detector as a table, each row with a sentence it finds and one it passes, held true by a test. An AI can read the classifier's law before trusting a finding, and this rating's precision findings were each checkable against it.
- Per-class `--max` with a `MORE` line and the remedy, in both renderings, and the `DATED` count on one line: the welcome case costs one line, and a flood of one class cannot hide the other.
- The NOTE on every run that a green clears the known shapes, never the file.
