# nova-memory READ and USE rating, nova-tools 1.2.0

Rater: Grok. Harness: Grok Build. Model: Grok.
Build: 81c24823a31d
READ: 7/10
USE: 7.5/10

Question: is this a good tool for an AI to use?

No v1.2.0 tag exists. This rates 81c24823a31d, the head of sprint/mechanical-2026-10-02 when the branch was cut (`git describe` says v1.0.0-6496-g81c24823a). Built and run on a Linux bench, in a throwaway directory of markdown: the banner's two-file corpus, the fixture corpus shipped with the tool, and a six-file notebook written for the trial (two practice notes, an index, a dated log, a handbook, one long paragraph). No live store, no server. The binary was built from a copy of that tree with no vcs stamp, so `version` printed `nova-memory devel linux/amd64 go1.26.6`, which is the floor internal/buildinfo names when the revision is absent. That word is not scored.

## Reasons

READ. The banner is a door an AI can use. One sentence says what the tool is for, how-it-works says the index is built in memory and nothing is written, setup is four lines, and the four example lines under it all exited 0 when run as written. Every verb's `-h` quotes its usage line from the banner, says `effect: inspection: reads, writes nothing`, and lists its flags. Required flags say why they are required. A bare `nova-memory` names the verbs and says quickstart is the first run. `serch` is refused with `did you mean search?`. Missing flags are one run, each with a hint (`bm25` or `trigram`, a k of 3 to 5). An unknown flag names itself and lists the flags the verb takes.

What keeps READ at 7. The first rule the banner teaches is not true of the example printed under it. cmd/nova-memory/main.go:54 says a hit whose score is at or below the CAL line is no better than noise, and the next lines show the example's rank 1 at score=0.99 under CAL 1.46. docs/CLI.md:416 then says a hit means something only when its score is clearly above CAL, over a transcript whose three right hits are 3.48, 3.12 and 2.97 under CAL 4.05. Running those commands reproduced both screens. An AI that obeys the written rule throws away the documented answers. The rule is not uniformly inverted: on the trial notebook `laser alignment drift` scored 4.62 against CAL 2.57, so a rare three-word query can clear it. A rule that the tool's own examples fail, and that some real queries pass, cannot be applied.

The rest of the help is thinner than the banner, and a few lines are wrong. `eval -h` still shows only `<gold.tsv>` (cmd/nova-memory/main.go:70); the row shape is in the spec and in the refusal, not in the help. `boot -h` calls the pin "the memories to load" (cmd/nova-memory/main.go:132) and docs/CLI.md:355 says the session loads exactly those memories; the verb prints `BOOT OK files=2 bytes=695` and no text. `verify -h` says `--root` is repeatable (cmd/nova-memory/main.go:376); two roots are refused. Every `-h` repeats the banner's exit-code paragraph, whose first clause is "exit codes: by verb (each ran here), search, stats, boot: 0 ran" (cmd/nova-memory/main.go:143), and the effect line on `version -h` says the index lives in memory for a verb that builds none (cmd/nova-memory/main.go:252). The spec's usage fence has no `--json` (docs/SPEC.md:2338) and its two-renderings paragraph still names only search and check (docs/SPEC.md:2408); stats, verify, eval, boot and quickstart all take `--json`. The spec calls the receipt a normalized snippet at a `file:para` (docs/SPEC.md:2572); the line is original text, cut, at `file:line`.

USE. The jobs a caller actually has worked, on the trial notebook, with bm25. A draft that repeated the kettle sentence ranked notes/kettle.md first at 28.38 against CAL 2.57, name=kettle-care type=practice, and rank 2 was the dated log, with the NOTE that a log hit means the event was recorded, not that the lesson was banked. A paraphrase that avoided the note's wording (mineral film, acid-free cloth, brass cloth) still ranked the optics note first, at 19.49. Two paragraphs were two candidates. `eval` on a two-row gold passed at floor 1, a planted miss exited 1, `--floor 0` was refused, and a row with no tab was refused with `format: query<TAB>expected[,expected]`. The shipped example gold, pointed at the fixture corpus it names, was `EVAL OK recall@3=1.000` on bm25 (mrr=0.929) and still recall 1.000 with bm25,trigram (mrr=0.857), so the banner's warning that fusion can measure worse is a real number, not a slogan. verify found a missing stem, a missing frontmatter name, and a dangling `[[storm-glass]]`, and `--exempt index` dropped the listing from the frontmatter check. `--links info` with no other check was refused, because a run that cannot fail is not a verification. boot accepted a two-file pin and refused an absolute path, a duplicate, a non-canonical path, an empty file, and a missing file. A second root was indexed in one ranking and each hit named its root. `--exclude 'log/*'` dropped the log. A query of words not in the corpus was exit 0 with a MISS line, not a bare zero. `--` before a dash word worked. A candidate of two terms was refused as unusable input, not as "you do not know this".

What keeps USE at 7.5. Obeying CAL, as the help states it, discards the banner's own right hit and every hit in the command-reference transcript. The receipt does not carry the passage. Snippets stop at 120 bytes (internal/memindex/channels.go:321), in the JSON too, and check cuts the candidate at 100 (cmd/nova-memory/check.go:82) before retrieval. Searching `spare lens etched ring` ranked the long note first and cut it at "the drawer sticks when the …", before the sentence that says the return spot sits inside the etched ring. Adding both channels reordered `warm vinegar cloth`: the log ranked above the practice note (fused 0.03306 against 0.03280) even though the practice note's bm25 score was higher (3.37 against 3.01), and search does not print the log-class NOTE that check prints, so rank 1 reads as the lesson. Coverage is a whole-word stem, not a link: appending "We do not cover lens here." to the index cleared the lens finding and the run exited 0. A pin with two missing files named only the first.

A 10 would make the CAL sentence true of the banner's example and of the command-reference transcript, or stop calling that probe a floor. It would put the answering passage in the receipt, describe the gold row on `eval -h`, say what boot actually prints, and carry check's log-class note on search.

## Good, keep

Nothing is written. Every verb's `-h` says so on the effect line, and a run leaves the tree as it found it.

Missing flags are one run, and each hint says what to put there. An unknown flag names itself and lists the verb's flags. A near miss on a verb suggests the verb (`serch` suggests search). `--floor 0` is refused because a harness that cannot fail is not a measurement. `--links info` with no other check is refused for the same reason.

check on a repeated draft scored 28.38 against CAL 2.57, named the practice note, and the log NOTE stopped the day log being read as the banked lesson. A paraphrase that did not copy the note's sentence still ranked that note first. The shipped example gold recalls at 1.000 on the fixture corpus.

verify keeps a frontmatter finding visible beside a wikilink finding, caps per kind, and the summary count is the total. boot refuses a pin that would load less than it names: absolute, duplicate, non-canonical, empty, missing.
