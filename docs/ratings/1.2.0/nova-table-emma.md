# nova-table READ and USE rating, nova-tools 1.2.0

Rater: Zhi (deepseek/deepseek-v4, in dsh, the DeepSeek Harness headless runner), a sprint worker on the re-rate card this file is named for
Build: 9c9b2ebc49fd
READ: 8/10
USE: 6.5/10

No v1.2.0 tag exists on the forge yet, so this rates the release candidate at the head of sprint/mechanical-2026-10-02, commit 9c9b2ebc49fd. `nova-table version` prints `nova-table v1.0.1-0.20261007202756-9c9b2ebc49fd linux/amd64 go1.26.6`. Built and run on a Linux bench. The root help, `help <verb> <subverb>` and all 40 verb, subverb and version `-h` pages were read cold. Then the banner example, the guide's Start-locally sequence, every verb's `example:` line and about ninety more calls ran against a throwaway Redis that listened on a Unix socket only (`--port 0`, no save, no append-only file), made inside the trial directory as the banner's own recipe says and shut down with `shutdown nosave` afterwards. No live store was touched.

## Reasons

READ. The banner says in one line what the tool is and in five lines how it works, names the store it needs, gives a store-less `--dry-run` example, and prints a four-line throwaway-store recipe that worked as printed. Every `-h` page has usage, an example, its flags grouped as flags / connection / write epoch and receipt where it has them, exit codes and an `effect:` line. `help cell`, `cell -h`, `help cell add` and `--version` all answer. An unknown verb, subverb, flag or argument count is refused in one line with the full list and a `run:` line naming the verb's page.

What keeps READ at 8. The banner is 127 lines and the column grammar, fold table, epoch rules and shell rules still come before the `example:` block. The same `effect:` sentence is repeated on all 19 table-write pages, and on the view pages it still names the table, its epoch, its rows and columns, and a bound cell, none of which a view has. `--score` and `--at-epoch` print as `<string>` when they take numbers. The banner's own line says `render` prints nothing at all when the table is empty, while an empty table draws its header, rule and footer as the guide and the renderer both say.

USE. The banner's example ran first time and drew the table it promised. The guide's Start-locally sequence ran as printed, including the percentage column and the stored view. Every verb's `example:` line ran except `cell move`'s, which moves an id the `cell remove` example had just removed. Every write prints a typed line with `trips=`, and `--receipt` adds the event id, epoch and both revisions. Formulas and folds compute exactly (`pct` pooled 50.0% over one of two, `sum`, `union`, `--exclude`). Bound cells, standing sorts, stale or ahead epochs, `col del` of an occupied column, duplicate adds and a binding into `table:*` are each refused with a runnable remedy. `--dry-run` on a write makes every check the real run makes and prints the call with `dialled=0 written=0`, with no store at all. `check` finds drift a raw write left behind.

What keeps USE at 6.5. The tool has a few dead ends and several silent no-ops. After a plain `drop`, `create` with another shape says `run: set --columns`, `set` says `run: create`, and neither names `drop --definition`, the one way out. A member id is one record for every table on the default prefix, so a batch `expect.absent` and `member create` for an id placed in another table refuse as existing, while `member find` in the second table says `unplaced`. `cell remove` of an absent id, or a list that mixes present and absent ids, prints the cell's size and exits 0, naming no removed or absent count. `cell move` from a column to itself prints a move. A hidden table named on the `watch` command line is dropped from the frame with no word. `render --width nope=1` for a column the table does not have is ignored at exit 0. `watch --out` writes its frame and says nothing. Only `batch` and `member read` take `--json`, so an AI cannot read `show`, `list` or `cell members` as JSON. A manifest that fails its schema exits 1, not the 2 a usage error gets.

The reading says: a careful tool whose writes can be trusted and whose refusals nearly always point the way. To reach 10 it needs the drop, create and set loop closed, member identity scoped the way the help describes, no-op writes that say they did nothing, and `--json` on the reads.

## Good, keep

The banner's throwaway-store recipe works as printed, and the unreachable-store refusal repeats it with the address it tried. Every write prints `trips=`, and `--receipt` gives the event id, epoch and both revisions. `--dry-run` makes every check the real run makes and prints the exact FCALL with `dialled=0 written=0`, with no store at all. Bound cells, standing sorts, stale or ahead epochs, `col del` of a column that holds a member, a duplicate add and a binding into `table:*` are each refused with a runnable remedy. Formulas and folds compute exactly (`pooled` 50.0% over one of two, `sum`, `union`, `--exclude`), an epoch snapshot reads back with `--at-epoch`, and `check` finds drift a raw write left behind. Layered help (`help cell`, `cell -h`, `help cell add`) answers with no store, and `shell --keep-going` names the failing line and keeps the highest status.
