# nova-memory READ and USE rating, nova-tools 1.2.0

Rater: Zhi, running deepseek/deepseek-v4 in the dsh headless runner, a friend on a re-rate card
Build: 9c9b2ebc49fd
READ: 8/10
USE: 8/10

No v1.2.0 tag exists on the forge yet, so this rates the release candidate at the head of sprint/mechanical-2026-10-02 as staged for this card. `nova-memory version` prints `nova-memory v1.0.1-0.20261007202756-9c9b2ebc49fd linux/amd64 go1.26.6`. Read cold from `nova-memory help`, every verb's `-h`, docs/SPEC.md:2335-2884 and docs/CLI.md:339-426, then built and run for real on a Linux bench machine, in a scratch directory made for the trial: a four-file corpus with real frontmatter, a listing, a dated log, a wikilink and a paragraph over the snippet cap; a second root; a gold file with a passing row, a missing row and a header-looking row; a pin file with two bad entries and a duplicate; and an empty corpus. No live store, no server, nothing written.

## Reasons

READ. The banner is the best door in the set. Line 1 says what the tool is for, `how it works:` names the index and says it is built in memory and nothing is written, `setup:` makes a corpus in four lines, and every line under `example:` runs unchanged from that corpus. Every required flag says why it is required, every verb's `-h` carries its synopsis, a worked example, an `effect:` line and its flags, and docs/CLI.md:339-426 is a real transcript with what the flags want and what the output means. The two READ defects the 1.2.0 candidate carried are fixed here: the banner now says CAL is context, not a cutoff, and a hit at or below it is not noise (cmd/nova-memory/main.go banner), so the tool no longer contradicts its own example; and `eval -h` now prints the gold format with a two-row example (cmd/nova-memory/main.go:259-262). The read caps, the exit codes and the no-defaults law are all stated.

What keeps READ at 8. Every verb's `-h` repeats the whole exit-code paragraph, and its first clause, `by verb (each ran here), search, stats, boot: 0 ran`, does not parse on a cold read (cmd/nova-memory/main.go:143). `version -h` and `boot -h` both say `(the index lives in memory for the run)` though neither builds an index (cmd/nova-memory/main.go:268). `verify -h` lists `--root <value> corpus root directory, repeatable (required)` while `verify --root a --root b` refuses with `names exactly one tree` (cmd/nova-memory/main.go:399). `eval`'s text `MISS` line escapes the query as `query=quokka\x20feathers` while `search` quotes the same field as `query="quokka feathers"`, so the same field has two shapes (cmd/nova-memory/eval.go:97). The `--coverage` help says a file is `named in some file`, but the check is satisfied by the stem appearing anywhere as bounded text (internal/memindex/verify.go:268); the spec says by stem, the help does not.

USE. The first run is the banner's: `quickstart --root ./corpus` runs stats, one search and one check, printing each command line above its output, and ends saying bm25 and k=3/2 were choices, not defaults. All eight verbs ran clean: `stats`, `search` (single and two channels, two roots, `--whole`, `--json`, a miss), `check` (file and stdin, `--whole`), `verify` (coverage, frontmatter, gate and info), `eval` (pass and fail), `boot` (pass, and escape, absolute and non-canonical pin entries), and `version`. Missing required flags, an unknown flag, an unknown channel, an empty channel entry, `--k 0`, `--floor 0`, a bad `--root`, an empty corpus and two `check` arguments each refuse once with a reason and a `run:` line; a miss is exit 0 with a `MISS` line that says out-of-vocabulary rather than not present; `--whole` prints a whole paragraph and marks a capped one `...+996B`; every receipt names its root, class, name, type and `file:line`; line numbers after three blank lines are right; the `***` name block is not frontmatter in either reader.

What keeps USE at 8. `stats --root ./corpus --exclude log/` exits 0 having excluded nothing (files=4, class=log still printed) while `log` and `log/*` both drop the class and no NOTE says the exclusion matched zero files (cmd/nova-memory/main.go:404-414). A header-looking first row in the gold file is scored as a query, so `query<TAB>expected` prints `EVAL MISS query=query expected=expected` and recall drops to 0.5 where it should be 1.0 (cmd/nova-memory/eval.go:153 skips only blank and `#` lines). `search --json` puts `"candidate": 1` on every hit, a field of `check` that the search line form does not carry (cmd/nova-memory/retrieval.go:75). A pin with two missing entries and a duplicate refuses at the first and names only that one, so the pin took two runs and the duplicate was never reported (cmd/nova-memory/boot.go). Missing-flag and unknown-channel refusals end `run: nova-memory help`, the whole banner, while the unknown-flag refusal on the same verb ends `run: nova-memory search -h` (cmd/nova-memory/main.go:383, main.go:368). `quickstart`'s demonstration ranks the index listing `notes/index-notes.md` above the note it lists, and takes the corpus's first paragraph (here a dated log) as the default draft.

## Good, keep

The index is built in memory on every run and nothing is written; every verb's `-h` says so on its `effect:` line. A refusal reports every missing flag at once, each with a hint that says what the flag wants, and an unknown flag lists every flag the verb takes. `--whole` prints the whole paragraph and marks a capped one `...+996B`, so a searched word past the old 120-byte cut is reachable and a cut is never silent. `--root` is repeatable and every receipt names its root; two roots rank in one list. A miss is exit 0 with a `MISS` line that distinguishes out-of-vocabulary from not present, and absent frontmatter prints `-` so the field count never changes. `verify` caps findings per kind with uncapped totals, `eval` refuses a floor of 0, and `boot` validates every pin entry's shape (non-canonical, absolute and escaping entries each refuse). The line numbers after blank lines are right, the two frontmatter readers agree about a `***` block, and `--json` is one envelope on every verb but version, a refusal included.
