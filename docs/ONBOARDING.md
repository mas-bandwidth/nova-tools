# ONBOARDING — a newcomer's first run

**A newcomer's first stumble is the spec for the onboarding points.**

The six points every command meets are in [STANDARD.md](STANDARD.md), under
**Help and refusal: the six onboarding points**, numbered as code cites them
("ONBOARDING point N"). A newcomer starts with `<tool> help`, pastes a line of
its `example:` block, and reads the tool's `### First run` in
[CLI.md](CLI.md).

## How feedback arrives

When you try a tool, say
three things, in this order: what works, so the author knows what to protect; where it catches or surprises you,
plainly, with the exact sentence it printed; and the fix you would make, a README line, a hint, a flag. Pure
criticism reads as an audit; pure praise leaves rough edges rough.
