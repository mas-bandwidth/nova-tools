# nova-sprint brand sheet

nova-sprint is a member of the Nova family: Nova is the seed, Nova Tools is
the workshop, and nova-sprint is the race. Its visual world joins the family's
four-point star and cheerful, rounded AI friends with a running track, lap cards,
and a finish flag. The race is about work moving through clear stages together;
it is not a contest between models or people.

## Name

Write the project and command name as **nova-sprint**: lowercase, with one
hyphen. Keep that spelling in headings, links, filenames, UI labels, and command
examples. In prose, use “nova-sprint” for the project or “the sprint” when the
reference is already clear. Keep “Nova” in the proper names “Nova Seed” and
“Nova Tools.” Do not turn the command name into `NovaSprint`, `Nova Sprint`, or
`Nova-Sprint`.

For a wordmark, set `nova-sprint` in Nunito ExtraBold (800), with the hyphen at
full height and ordinary letter spacing. At sizes where the full wordmark is
hard to read, use the star-and-track mark without squeezing or abbreviating the
name. Do not redraw letters as a separate logo or add a slogan inside the mark.

## Mark

Use [`assets/sprint/nova-sprint-race.svg`](../../assets/sprint/nova-sprint-race.svg)
as the original header illustration. It shows two robot friends running at
different paces, a golden Nova star, a lap card, and an open finish flag. Blue
and rose runners have friendly, simple faces; the careful runner is still
moving. The flag marks progress, not a podium. The art has a dark navy field so
it sits naturally above the dark dashboard; preserve its proportions and clear
space when placing it.

For a compact mark, use the gold four-point star with one blue curved lane.
Keep the star clear of text and UI badges. Do not use a trophy, a speed ranking,
a finish order, or an image of one model defeating another. Do not stretch,
recolor the runners to imply model tiers, or put dashboard data into the static
art.

## Colours

The dashboard's dark palette is the default. Use these brand accents around its
existing surfaces and status colors:

| Role | Dark value | Light value |
|---|---|---|
| Page background | `#0D0F12` | `#F5F7FA` |
| Raised surface | `#14171B` | `#FFFFFF` |
| Main text | `#EEF0F3` | `#19212B` |
| Quiet text | `#A4AAB4` | `#596574` |
| Track and divider | `#262A31` | `#DFE5EC` |
| Nova star | `#F2BE4C` | `#8A5B00` |
| Running lane blue | `#3987E5` | `#226AC4` |
| Friend rose | `#D55181` | `#A92F60` |
| Helpful warm accent | `#FB8321` | `#A74B00` |
| Landed green | `#199E70` | `#117653` |

The dark values match the dashboard's existing background, surfaces, text,
track, work, reader, review, and landed tokens. In light layouts, use the light
column for equivalent roles and keep text/background contrast strong. Status
colors retain the meanings defined by the dashboard; accents decorate the
brand and never replace status labels. Use gold for the Nova star, blue for the
lane, and rose or orange as small friend accents. Avoid a rainbow gradient,
large red fields, and color alone to communicate a card state.

## Type

The wordmark uses the dashboard's bundled **Nunito 800**, licensed under the
SIL Open Font License 1.1; its license and source are recorded beside the font
in the repository. Use Nunito for short headings when it is available. Use the
system sans-serif stack for body text and a readable monospace face for command
examples, identifiers, and card states. Keep headings compact and sentence
case. Do not introduce a second display face or set long paragraphs in the
wordmark weight.

## Voice

Docs and help are warm, plain, and specific. Explain what a card or gate does,
what it is waiting for, and what a person can do next. Let jokes come from
familiar work mishaps—an overlong nap, a tangled dependency, a lap card held
upside down—and aim them at the situation. Treat careful and fast work as
useful at different times. The machine records and checks transitions; it does
not have feelings or replace human judgment.

**Do:** “Two cards are ready. One is waiting for its dependency to land.”

**Don't:** “The robots are racing because Purple is lazy and Yellow is a genius.”

**Do:** “The check is still red. Fix the failing test, then run the gate again.”

**Don't:** “Victory! The machine knows the whole team is happy.”

**Do:** “A slower review can catch the edge case before the change lands.”

**Don't:** “Fast models win. Everyone else is holding up the race.”
