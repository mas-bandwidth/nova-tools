# The kinds this toolchain DECLARES, one per line, with a one-line description
# after a tab (SPEC-TOOLWORK.md hygiene rule 6).
#
# This file is DATA, not code, and it is embedded into the binary, for the same reason
# stray.txt is: a list a reader can open and diff is auditable and a list spelled out in
# a function is not.
#
# There is no default kind. A kind that is not in this file is refused by name.
#
# Format: <kind><TAB><what the card does><TAB><gated|ungated>
#
# The third field is gated or ungated. A missing third field, or any other
# value, is gated. ungated is the only value for which TEST: none is a
# declaration. The field selects no command.

fix-red	fixes one defect, red test first	gated
transcript-test	makes one docs/TESTS.md section executed line for line	gated
rebase	replays one of our own open PRs onto the base, changing nothing	gated
sweep	applies one mechanical class fix at every site the class test names	gated
mutation-kill	writes the test that kills one surviving mutant	gated
guard	reverts one commit's non-test files; the named tests must go red	gated
read	read and report	ungated
probe	read and report	ungated
text	read and report	ungated
tone	read and report	ungated
report	read and report	ungated
