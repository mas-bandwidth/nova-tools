# Every program the functional tier runs by name, and what carries it.
#
# One row per name: `<name><TAB><how><TAB><provider or reason>`.
#   apt     an apt package named in the Containerfile's apt-get install
#   source  a pinned download or source build; the provider is a word the
#           Containerfile must contain (a stage name or the binary's own name)
#   base    the base image's own package (coreutils, bash, dash); not installed here
#   tree    built or stubbed by the tests from the checkout
#   absent  not in the image, with the reason it can be done without
#
# internal/ci TestFunctionalImageCarriesEveryBinaryTheTierExecs reads every Go
# file under cmd, internal and tools for a name given to exec.Command,
# exec.CommandContext or exec.LookPath as a string literal or a package-level
# constant, and holds this list to that set in both directions: a program run
# and not listed is red, and a row that no file runs any more is red. The rows
# below `[unscanned]` are programs the tier needs that a name in a Go file does
# not show (a script, a list of candidates, a path built at run time); the
# Containerfile must still carry them.
