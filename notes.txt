# CARD-8031 / nova-tools #673 -- diff-only + --files for nova-review packet

## Red test (before fix), verbatim -- the packet diff still carries the

        ```diff
        diff --git a/a.txt b/a.txt
FAIL

The fix: `--diff-only` runs `git diff --unified=0` and then strips the
function/section name git leaves after the closing `@@` (`@@ -3 +3 @@ beta`),
so only the changed lines survive. `--files <glob>` appends `-- <glob>` to the
same diff to narrow it to matching files. --reuse refuses both, beside the
flags it already refuses.
