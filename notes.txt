CARD-8053 — nova-tools issue #562 — nova-review packet: --out under a symlinked cwd (macOS /var -> /private/var) is refused as escaping

THE ISSUE (verbatim refusal line, printed by main.go:112):
  PACKET REFUSED: --out escapes the current directory and the lane; give a relative path under the current directory or an absolute path under the current directory or the lane
  Cause: on darwin t.TempDir() is under /var/folders/..., a symlink to
  /private/var/folders/.... os.Getwd() returns the resolved spelling while --out
  carries the unresolved one (or vice versa); underDir(root, path) compared the two
  spellings with filepath.Rel without symlink evaluation, read two names for one
  directory as "../..", and refused a path genuinely under cwd.
  Reported by Emma (dogfood, 2026-09-15, adoption at 4f1defd8).

WHAT I FOUND ON THIS BRANCH, READ BEFORE ANY EDIT (spec: docs/SPEC-REVIEW.md:834-846
"## The packet file", synopsis :591; docs/CLI.md:702-734; code: packet() main.go:75,
outEscapes() main.go:451, underDir() main.go:465, resolveExisting() main.go:494):
  The fix the issue asks for is ALREADY on origin/main, and therefore on this
  branch (rowan/issue-562 cut from a9fa1a6): commit b4c9d27 (PR #563, the "macOS
  coverage" sweep that also redid CI) added resolveExisting() and the two calls
  in underDir() at main.go:479-480. It resolves both sides through the longest
  EXISTING ancestor, which is strictly stronger than the issue's proposed
  "smallest fix" (plain filepath.EvalSymlinks with fallback): --out names a file
  whose absence is the point, EvalSymlinks refuses a path it cannot stat, and the
  plain fallback would keep the unresolved spelling and stay red. b4c9d27 and
  Emma's adoption 4f1defd8 are both ancestors of this branch's head.
  The existing test TestPacketAcceptsAbsoluteOutUnderCwd (main_test.go:633, from
  PR #412) covers the reported scenario but only goes red when TMPDIR itself is
  reached through a symlink (darwin's /var/folders). This sandbox's TMPDIR is a
  plain path and the harness refuses writes outside ./repo and ./scratch, so that
  test cannot exercise the mismatch on this machine — shown green pre-fix below
  for exactly that reason. The gap this card could still close: a deterministic
  test that builds the two spellings itself, red pre-fix on any POSIX machine.

THE NEW TEST (cmd/nova-review/main_test.go, after TestPacketAcceptsAbsoluteOutUnderCwd):
  TestPacketAcceptsAbsoluteOutUnderSymlinkedCwd builds two spellings of one
  directory — physical := t.TempDir(), an alias symlink to it in a second
  t.TempDir() — chdirs in through the alias (os.Getwd() then reports the resolved
  spelling) and passes --out spelled through the alias. That is the darwin
  /var -> /private/var shape built in-test, red pre-fix on any POSIX machine,
  green post-fix, and independent of the machine's TMPDIR. It skips only where a
  symlink cannot be created at all.
