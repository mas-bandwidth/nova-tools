CARD-8100 / issue #186: Coordination: audit live and completed work, then turn
retrospectives into measured improvements.

This issue is a proposed learning loop (ROADMAP RD-23 / E10-F06), not one
concrete verb. This card takes the narrow, codeable slice that maps to an
explicit sentence in the desired behavior -- "Do not invent the cost or quality
[of an unrun alternative]" and "Unknowns remain visible" -- in the coordinator's
audit path, `nova-pulse status` (the live view). The `RATE` line fabricates a
zero cost and a zero latency when no usage.tsv row is measured in the window:
`usd_per_card=0.0000`, `p50_s=0`, `p90_s=0` say "measured zero", which is false,
it is unseen.

Red test (before the fix), verbatim:
  --- FAIL: TestStatusRateUnknownsStayVisible (0.06s)
      status_test.go:228: RATE must leave unmeasured metrics unknown (-), got:
          STATUS WIDTH a running=0 slots=1 load=0 headroom=1
          STATUS QUEUE pending=0 gated=0 launched=0 done=0 failed=0
          STATUS RATE cards_per_hour=0 p50_s=0 p90_s=0 usd_per_card=0.0000 parallelism=0.0
          STATUS REMAINING queue=0 unread_prs=0 dirty_prs=0 uncarded_issues=0 hours=0
          STATUS CONTRACTION hour cards=0/0 prs=0/0 issues=0/0 verdict=CONVERGING
          STATUS CONTRACTION day cards=0/0 prs=0/0 issues=0/0 verdict=CONVERGING
          STATUS ADOPTION glenn version=- receipt=0 edges=0
          STATUS OPEN dogfood=0 holds=0 escalations=0
          STATUS TOOLS merged_since_adoption=0

Root cause: rateOf returns a rateLine whose default string fields read "0.0000"
and "0.0", and whose int fields read 0, when there are no usage.tsv rows in the
day window; Status prints those values verbatim, so an unmeasured cost and
latency render as measured zero.

Fix (smallest change):
  - internal/pulse/status.go: add a known flag to rateLine; rateOf returns
    known=false (and empty metrics) when no row is in the window; Status prints
    "-" for every RATE metric when !known, using the status verb's own unknown
    token (ADOPTION already renders version=- for an unmeasured friend).
    remainingOf is unchanged: it parses the empty parallelism/p90 to their
    existing floor of 1, so REMAINING is byte-identical.

Docs updated byte for byte:
  - docs/SPEC-PULSE.md: the RATE bullet and grammar note that with no measured
    usage every metric reads "-", never zero.
  - docs/CLI.md: the same sentence on the status RATE line.
