## Root cause

The help text (main.go:21) advertises `[--max <n>]` for the pool verb,
but the cmdPool function's flag set did not define the --max flag.

## Fix

Added `max := f.fs.Int("max", 0, "")` to cmdPool's flag set,
added validation for negative values, and passed `Max: *max` to pulse.Pool().
